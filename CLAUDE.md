## Commands

```bash
npm start            # Metro bundler / Expo dev server
npm run android      # open on Android device or emulator
npm run ios          # open on iOS simulator (macOS only)
npm run web          # open in browser
npx tsc --noEmit     # typecheck (the only check in the repo)
```

There is no test runner and no linter configured. `npx tsc --noEmit` is the only automated verification available — run it after changes.

## Architecture

Bare Expo SDK 57 app (React 19.2 / React Native 0.86 / TypeScript 6, `strict: true`), still close to the blank template.

Entry chain: `index.ts` calls `registerRootComponent(App)` → `App.tsx` is the root component. There is **no expo-router and no navigation library installed** — routing is not file-based, so a new screen only renders once it is wired in from `App.tsx` (or a navigator added on purpose). Adding `expo-router` would mean moving to an `app/` directory and changing `main` in `package.json`.

`src/` is scaffolded but empty, with the intended split:
- `src/components/` — reusable UI
- `src/screens/` — screen-level components
- `src/services/` — API/data access

Import through the `@/*` → `src/*` alias (`import { X } from '@/services/api'`). The alias lives in `tsconfig.json` `paths` with **no `baseUrl`** — `baseUrl` is deprecated in TypeScript 6 and reintroducing it fails the typecheck; keep `paths` entries relative (`"./src/*"`).

`/ios` and `/android` are gitignored: native projects are generated by prebuild, so never hand-edit them and prefer config plugins / `app.json` for native configuration.
